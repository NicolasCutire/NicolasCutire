## Para conciliar el sueño (inicio)

### 1. Pulsos de ruido rosa sincronizados con ondas alfa
**Estudio:** SLEEPFAST / Elemind (2024) — [paper](https://www.nature.com/articles/s41598-024-63385-1)

| Parámetro | Valor del estudio |
|---|---|
| Estímulo | Pulsos de ruido rosa en fase con alfa individual (7,5–12,5 Hz) |
| Fondo | Lluvia natural a −18 dB respecto al pulso |
| Duración | 30 min al apagar las luces |
| Objetivo | Reducir latencia de inicio del sueño (~10,5 min) |

## Para sueño profundo / ondas lentas (N3)

### 7. Clicks de ruido rosa en bucle cerrado (closed-loop)
**Estudios:** Ngo 2013, Besedovsky 2017 — [Neuron](https://doi.org/10.1016/j.neuron.2013.03.006) · [Nature Communications](https://doi.org/10.1038/s41467-017-02170-3)

| Parámetro | Valor del estudio |
|---|---|
| Estímulo | 2 bursts de ruido rosa de **50 ms**, 5 ms rampa |
| Volumen | **50–55 dB SPL** en auricular |
| Sincronización | En fase con ondas lentas EEG (~0,8 Hz) |
| Duración | 120–210 min durante NREM |

| Enlace | Tipo | Notas |
|---|---|---|
| 🔬 [SleepSpace — Deep Sleep Stimulation](https://sleepspace.com/deep-sleep-stimulation/) | App | Implementa clicks ~0,8–2 Hz con detección de sueño |
| ≈ [Freesound — Pink Noise 60 min](https://freesound.org/people/hear-no-elvis/sounds/120928/) | Descargar | Ruido rosa base (sin sincronización EEG) |
| 🔬 Paper + métodos | [PDF Ngo 2013](https://www.inb.uni-luebeck.de/fileadmin/files/publications/inb-publications/pdfs/NgMaBoMo13.pdf) | Especificación exacta del estímulo |

### 8. Pulsos rítmicos a 0,8 Hz (ruido rosa 50 ms)
**Estudios:** Bellesi 2012, Papalambros 2015 — [paper Bellesi](https://doi.org/10.1111/j.1365-2869.2012.01039.x)

| Parámetro | Valor del estudio |
|---|---|
| Estímulo | Burst rosa **50 ms** cada **1,25 s** (= 0,8 Hz) |
| Volumen | **60 dB SPL** 🎧 |
| ⚠️ | Retrasa inicio del sueño si se usa **despierto** |
| ✅ | Aumenta ondas lentas **una vez dormido** |
